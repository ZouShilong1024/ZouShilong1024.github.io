## 本地启动

需要 Python 3。在本文件所在目录执行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 可将 `python3` 换成 `py`。打开 http://127.0.0.1:8000/ 。
网页采用原生 HTML/CSS/JavaScript，无需 npm 安装；ES 模块必须通过 HTTP 访问。
Tailwind 和 Google Fonts 来自 CDN，完整样式和字体需要联网。

## 修改入口

- `index.html`：页面结构、文案和任务按钮。
- `assets/css/site.css`：样式。
- `assets/js/demo-data.js`：数据集及任务目录。
- `assets/js/main.js`、`overview.js`、`reverse-gallery.js`：动态素材路径及画廊逻辑。
- `assets/js/page-ui.js`：导航、应用标签页和引用复制。
- `docs/paper-alignment.md`：技术内容与论文的对应关系。

切换任务时会动态拼接素材路径，不能只根据 HTML 的直接引用删除视频或封面。

## 测试和构建

测试和构建还需要较新的 Node.js；无需第三方 npm/Python 包。

```bash
node --test tests/media.test.mjs
python3 scripts/build-site.py
```

构建产生 `dist/` 和 `build-report.json`，并检查静态和动态引用的素材是否存在。
如需压缩发布视频，安装 FFmpeg（包括 ffprobe）后执行：

```bash
python3 scripts/build-site.py --compress-videos
```

此命令只压缩输出目录内的视频，保留源码素材。当前网页使用 98 个视频。

## 包内容和部署配置

本包未包含 `.git/`、`dist/`、构建报告、运行日志和项目外的未使用素材备份。
README 中的外部备份路径属于原开发者电脑，不是运行依赖。
`.openai/hosting.json` 保留原项目的 Sites 关联；如需部署为独立 Sites 项目，应使用新项目配置。
本地预览不需要 Sites 账号。GitHub Pages 发布方法见 README。
`docs/sites-upload-diagnostics.md` 是历史部署排查记录，并非当前构建步骤。

ZIP 不含 Git 历史；如需独立版本管理，可在解压后执行 `git init`。
